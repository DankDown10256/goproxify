Concevoir et installer l'infrastructure

Accès root
Cette page installe des conteneurs sur ce serveur. Le code d'accès circule en clair sur le réseau local (HTTP) : ne l'ouvrez que depuis un réseau de confiance, ou publiez le port sur 127.0.0.1 et passez par un tunnel. L'Admin est unique et se trouve sur l'hôte de ce launcher : c'est lui qui référence les autres hôtes.

1 Point de départ

Pour un Admin perdu dont les passerelles tournent encore : le launcher reprend de la sauvegarde le secret racine, le certificat et la topologie, et installe un Admin que les hôtes en place reconnaissent. Les données (comptes, proxys, règles) se restaurent ensuite dans l'Admin.

2 Hôtes

Déclarez les machines et leurs rôles. Ce launcher installe celle sur laquelle il tourne ; les autres sont déclarées dans l'Admin, qui affichera pour chacune un QR code d'installation.

3 Premier compte administrateur

Le mot de passe est généré et affiché une seule fois à la fin.
